# Guitar Scales

Visualize your guitar scales, find voicings and learn the intervals!

Check it out here: https://guitarscales.harmen.dev/

## Features

### The fretboard
- Every scale and mode across a 21-fret neck, with the root in red, scale tones in cream and chord tones in blue
- Show **notes**, **intervals** or plain **dots**
- Show only the scale, or every note on the neck with the rest dimmed
- Tap any note to hear it, or play the whole scale up one octave
- Light and dark mode

### Positions
- **Full neck**, or one numbered position per scale degree
- **Box**: a five-fret window starting just below that degree on the low string
- **3NPS**: three notes per string for seven- and eight-note scales
- **2NPS** for pentatonics, which gives the five classic pentatonic boxes

### Keys and spelling
- The key is the root of the mode, so C with Dorian gives C Dorian
- Notes are spelled the way the scale is written: one letter per note in seven-note scales (C D E♭ F♯ G A♭ B), so degrees and chord numerals read correctly
- Choose sharps, flats or automatic spelling

### Chords
- The chords of every scale degree, with roman numerals and their notes
- Chord names are worked out from the notes each chord contains
- Pentatonics show the fullest standard chord built only from scale notes
- Select a chord to light up its tones on the neck

### Tunings
- Built-in tunings, plus your own custom tunings
- Every setting is kept in the URL, so you can share exactly what you see
